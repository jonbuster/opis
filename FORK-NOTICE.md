## Fork modifications

This fork adds and changes code for custom OpenAI-compatible AI providers,
including a user-facing provider settings window, custom endpoint support, and
provider refresh behavior across the editor tabs. Modified source files carry a
`MODIFIED FILE NOTICE` identifying this fork. New fork files carry the same
attribution reference.

No API credentials are included in this repository. Credentials entered by an
end user are stored in the local Electron user-data settings file and are sent
only to the endpoint selected by that user. Anyone distributing Opis should
provide an appropriate privacy notice and should not collect, publish, or
embed users' API keys.
